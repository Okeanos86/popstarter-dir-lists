# popstarter-dir-lists
Lists of game IDs and folder names for the DISCS_DIR.TXT option of [UDPFS Assault](https://github.com/Okeanos86/BDMAssault/tree/udpfs) and [BDM-UDPFS Assault](https://github.com/Okeanos86/BDMAssault/tree/bdm_udpfs) (DISCS_DIR=1 in PATHMAP.INI), extracted from the libretro-database PlayStation RDB.

Sony - PlayStation MULTI DISCS ONLY.txt: only multi-disc games, with all their discs on one line.
Sony - PlayStation.txt: every game, multi-disc games included.

Copy the one you want to POPS/DISCS_DIR.TXT.

The lists are derived from the libretro-database PlayStation RDB (Sony - PlayStation.rdb) by the libretro team and contributors, licensed under CC BY-SA 4.0. Changes: the entries were extracted and rewritten as ID,ID=Name lines for DISCS_DIR.TXT; characters not allowed in folder names were replaced. These lists are released under the same license, CC BY-SA 4.0.
